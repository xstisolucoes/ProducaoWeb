# Validação da Etiqueta de Produto Acabado

Em 20/08/2026, a prévia de referência foi gerada pelo jsreport usando Chromium com tamanho físico A4 (`594,96 × 841,92 pt`) e uma página por palete. A conferência visual confirmou a margem superior de 55 mm, os blocos de cliente, referência, estoque, palete, inspeção, QR Code OP, lote e fabricação conforme o modelo FastReport recebido.

O ambiente de desenvolvimento Linux exigiu `PRODUCTION_CHROMIUM_PATH=/usr/bin/chromium` para a validação. No proxy Windows de produção, a mesma rotina mantém a detecção automática de Google Chrome ou Microsoft Edge já utilizada pela Etiqueta de Processo.
